# QuickLink — Сервіс скорочення URL-посилань

**QuickLink** — це статичний вебдодаток для оптимізації довгих посилань. Проєкт реалізований як багатосторінковий сайт з адаптивним інтерфейсом, що коректно відображається на смартфонах, планшетах та десктопах.

## 🚀 Функціональні можливості

* **Скорочення URL**: форма для введення довгих посилань та генерація компактних адрес.
* **Управління посиланнями**: таблиця зі списком створених посилань, кількістю кліків та можливістю редагування/видалення.
* **Авторизація**: сторінки входу та реєстрації для користувачів.
* **Особистий кабінет**: перегляд даних профілю (ім'я, email, стать, дата народження).
* **Про продукт**: інформаційна сторінка з описом сервісу.

## 🛠 Технології

* **HTML5** — структура контенту.
* **Bootstrap 5.3.0** — стилізація та адаптивна сітка.
* **Bootstrap Icons** — графічні елементи інтерфейсу.

## 📂 Структура проєкту

Проєкт складається з 5 основних сторінок:
1.  `index.html` — Робоча сторінка сервісу.
2.  `about.html` — Про додаток та автора.
3.  `profile.html` — Профіль користувача.
4.  `login.html` — Форма входу.
5.  `register.html` — Форма реєстрації.
